NurDiyanaAziz’s Portfolio
This repository hosts my personal developer portfolio — a responsive, modern website built with React (bootstrapped using Create React App). It showcases my skills, projects, and experience, and serves both as an online CV and a hub for my work.

Key Features

Projects Showcase: Highlight of my key projects, with links to demos and code

Responsive Design: Works beautifully on mobile, tablet, and desktop

Tech Stack: Built with React, JavaScript, CSS, HTML

Deployment Ready: Easy to deploy on GitHub Pages or other static hosting

Clean, Minimal UI: Designed to focus on content, readability, and user experience
